## 启动与访问

```bash
python3 -m fnet                 # 自动打开 http://127.0.0.1:8765
python3 -m fnet --no-browser    # 只启动服务
```

WebUI 默认只监听本机，启动时生成随机 token 并注入页面，所有写操作都要带
`X-Fnet-Token`。服务用 Ctrl+C 停止，也可以在“文件”菜单里选择“停止 WebUI 服务”。

## 界面分区

| 区域 | 内容 |
| --- | --- |
| 顶栏 | 全局功能搜索、文件 / 统计 / 设置 / 工具 / 专项功能 / 帮助菜单、tshark 状态、语言切换、主题切换 |
| 左侧栏 | 上传区、抓包路径、“最近使用”与按分类折叠的 56 个功能（功能搜索在顶栏） |
| 主区域 | 分析日志、分析结果、产出文件、批量队列、统计图表、任务历史、文本工具、关于 |
| 底部 | 进度条、状态徽章、Toast 提示 |

## 上传与选择功能

1. **上传抓包或日志**：把文件拖进左侧虚线框，或在下方的输入框填入本机绝对路径后点“使用”。
   pcap / pcapng 与 `.log` / `.txt` / `.jsonl` / `.csv` 都可以；检测到日志时会自动
   切换到日志功能。同时拖入多个文件会进入**批量队列**，逐个排队分析。上传大文件时
   显示百分比，按 `Esc` 或重新选择文件可以中止，服务端会清理未完成的临时文件。
2. **勾选功能**：左侧按 14 个分类折叠展示，每个功能旁有复选框；顶部“全选”可以一次
   勾选，搜索框支持按名称、说明、分类与功能名过滤。
3. **最近使用**：常用的复选框会记在浏览器本地，显示在搜索框下方，一点即用。
4. **填写参数**（可选）：左侧的参数面板默认折叠，按需展开：

| 面板 | 用途 |
| --- | --- |
| Webshell 解密设置 | 连接密码 / 密钥、HTTP 过滤器 |
| Shiro 解密设置 | `rememberMe` 的 Cookie 名、Base64 密钥、CBC / GCM |
| WinRM 解密设置 | NTLM HASH 或密码、端口 |
| SQL 盲注设置 | 正则、成功条件、时间阈值、已保存的盲注日志 |
| 日志关联设置 | 关联日志路径（`log_extra_paths`）、时间窗口、活动簇间隔、命令风险阈值 |
| 通用分析设置 | 自定义关键字、字典路径 |

TLS 解密所需的 keylog 或私钥在“设置”菜单里上传，上传后会合并进当前配置，
下一次分析生效。

## 运行与取消

点击“开始分析”后，状态徽章依次显示排队、运行、完成；进度条按功能推进。
“取消”会中断当前功能，已经写出的日志与产出会保留。单个功能失败不会终止任务，
错误会以红色日志行记录，其余功能继续执行。

运行中还可以点“暂停”：任务会在**当前功能结束后**停在功能边界，已完成的
功能状态写进 `job.json`；点“继续”或命令行 `--resume <job-id>` 从下一个未完成
功能接着跑。无状态功能可以用 `--shards N` 按帧区间分片加速。

## 语言切换

顶栏的下拉框可在中文 / English 之间切换。界面外壳、功能标题、功能说明与分类
名使用 `title_en` / `description_en` / `name_en`；日志与报告保持中文，确保证据
文本在不同语言下一致。选择会保存到配置，下次启动沿用。

## 分析结果

日志里值得汇总的内容（凭据、哈希、flag、还原的文件、Webshell 输出等）会进入
“分析结果”表格：

- 默认按时间倒序排列（新增“时间”列），点击表头可切换升序/降序并回到默认排序
- 按类别与级别筛选，按摘要、详情、帧号、功能搜索
- 点击表头排序，调整每页条数并翻页
- “列显示”可隐藏不关心的列，设置保存在浏览器本地
- 复制本页、复制选中行，或导出 CSV
- 点击“帧 N”打开数据包详情，查看上下文并导出 pcapng 片段
- 哈希类结果（NetNTLM、Kerberos、NTLM、WPA 22000）的详情弹窗提供
  “用 hashcat 破解”：可选字典、加速档位 `-w`、`-O`、`--force`、超时与
  附加参数，日志与破解结果实时显示；字典路径与参数会保存到配置
- 详情弹窗会自动检测疑似 Base64 / Hex / URL 编码串并提供“一键解码”面板：
  默认解码第一处命中，多步解码链逐行展示，`flag{...}` 自动高亮，也可一键
  复制或直接在浏览器里打开 CyberChef
- 表格上方的 Flag 汇总条列出本任务发现的全部 flag（去重保序），可复制；
  `flag` 前缀统一小写，原文存 `extra.raw_flag`，详情会注明原文写法
- DNS/ICMP/TCP/UDP 的长度与时序隐蔽信道统一记为协议结果，`extra.kind`
  区分长度/时序、`extra.protocol` 标明协议、`extra.variant` 是命中的读法，
  解出的文本落盘并在详情里给出预览，带 flag 时另有一条独立的 flag 结果
  隧道载荷结果的详情弹窗还会显示“载荷”面板：预览重组文本、下载原文件，
  “破解”展开口令/候选口令/算法/摘要/盐表单，留空即自动尝试常见配方，
  命中后显示明文与 flag，并把解密文件写回任务目录

任务结束时同样的数据会写入输出目录的 `findings.json` 与 `findings.csv`。

### SMB3 加密流量

来自 SMB3 加密会话的结果（“SMB 加密链路智能串联”给出的“SMB3 加密流量”等）
详情弹窗底部提供“解密 SMB3”，弹出的对话框会尽量自动填好：

- 明文密码：来自 NTLM 验证或 SMB 密码候选的命中结果
- 账号与域：来自 SMB NTLM 认证结果
- 会话密钥：上次 SMB3 解密留下的 `smb3_keys.txt`
- TCP 流：当前结果所在的那条流

NetNTLMv2 哈希要先破解成密码，只有 32 位十六进制的裸 NT 哈希才会直接填进
“NT 哈希”框。对话框下方的“重新检测”按钮会在不关窗的情况下重新查找线索，
只补你没有改过的输入框；线索不足时，先跑一次 NTLM 验证或 SMB 密码候选，
或者手工填入。多个账号可用表单顶部的下拉框切换，选中即填入对应的账号、域、
TCP 流与密码。

日常发现（SMB 协商方言、候选密码数量等信息级行）只出现在分析日志与 `smb_password_candidates.txt` 中，不再出现在“分析结果”里；可操作的结果由 `SMB加密链路智能串联` 与 `NTLM HASH提取` 承担，恢复的旧任务仍可能包含那些旧行。

解密成功后，会话密钥会逐条列出，还原的文件与 `smb3_keys.txt`
出现在“产出文件”页。

## 数据包定位

日志与分析结果中的“帧 N”是按钮：

- 弹窗显示该帧的摘要、前后文帧和 `tshark -V` 解码详情
- 可一键导出包含上下文的小 pcapng 片段
- 检测到 Wireshark 时可直接打开对应帧

## 产出与报告

“产出文件”列出本次任务写出的哈希、还原文件、解密结果等交付物，可单个下载或
打包下载。报告本身不在此列，请从“文件”菜单或“分析结果”页导出。分析结果类
文件（`findings.json`、`findings.csv`、`annotations.json`、`log_*.csv` 等）
也不出现在产出列表中：详细发现直接在“分析结果”页与“统计图表”实体统计卡片
查看，文件仍在磁盘上，可通过 `/api/download?job=<id>&path=<file>` 精确下载。
“文件”菜单提供：

- 查看 HTML 报告 / 导出分析报告：自选章节（任务详情、功能清单、关键发现、
  完整日志、产出文件、分析参数），HTML 自带样式、无需联网，可直接打印成 PDF
- 下载纯文本报告
- 一键导出所有文件 / 一键分离文件 / 修复流量包 / ETL 转 pcapng

## 批量队列

一次拖入多个 pcap 后进入“批量队列”页：

- 按并发数排队执行，可暂停 / 继续、拖拽调整顺序、取消单个任务
- 逐个查看日志与结果
- 结束时把选中或全部任务合并为一份 Markdown / HTML 报告

## 统计图表

“统计图表”页基于当前任务生成：

- **流量时间线**：滚轮缩放、拖拽框选，点击时间桶下钻到对应帧
- **协议分层**与 **Top 会话**：点击条目过滤
- **会话拓扑**：节点为端点、边为会话，按字节数加权
- 图表可导出 SVG / PNG
- 文本日志任务同样可用：时间线按日志时间戳聚合事件数，协议分层显示
  error/warn/info/debug 级别计数，“Top 会话”显示 **Top 实体**
  （client_id/user/IP），拓扑在日志同时包含客户端 IP 与对端标识
  （server/host/program）时绘制；日志没有字节数，图表按条数加权，无法
  统计的面板会显示具体原因（如“日志中没有可解析的时间戳”）
- **实体统计**（仅日志任务）：按维度查看完整实体统计表。维度下拉框列出
  当前日志实际可用的维度（client_id/user/IP/网段/字段等，默认 client_id），
  切换或点“刷新”即重新统计；表格上方为 Top 10 横向条形图，表格列包括
  值/次数/占比/失败次数/失败率/成功次数/成功率/首次/末次。可选参数
  `success_regex` / `fail_regex` / `subnet_prefix` 与日志功能的任务参数同
  口径，非法时自动回退（默认失败规则、非失败即成功、/24 默认、范围 8–32、
  IPv6 固定 /64）；数据超过 50 条时提示“仅显示前 N 条，完整数据见
  log_entities.csv”。维度不在该日志的可用列表时，卡片内给出原因和可用维度

## 任务历史

每次分析都会记录抓包名、功能、参数、日志与产出。“任务历史”页可以：

- 回看报告与日志，下载产出
- 一键重跑（沿用原参数）
- **对比两个任务**：选择基准与目标任务，查看新增 / 消失 / 共有的凭据、哈希、
  flag 等结构化结果（调用 `/api/compare`，与 CLI `--compare` 同一实现）
- 删除单条记录

历史记录写入本机缓存目录；在共享机器上用 `FNET_HOME` 隔离，或分析完后删除。

## 设置与实时抓包

- **自定义规则**：“设置 → 自定义规则…”导入逐行正则或 YARA 子集规则文件，
  命中写入“分析结果”的“自定义规则”类别并进入报告；路径保存为
  `paths.rules_file`，命令行可用 `--rules` 为单次任务覆盖。
- **实时抓包**：工具栏“实时抓包”选择 `tshark -D` 列出的网卡与 BPF 过滤器，
  抓包写入缓存目录的 `live/`；停止后可以直接把结果提交给当前勾选的功能。
  同一时间只允许一个抓包进程，重复“停止”不会影响已保存的文件。

## 主题与外观

提供暖夜、暖昼、浅樱、暮玫、莓紫五套配色，选择保存在浏览器本地；窄屏下自动
堆叠为单栏布局。

## 安全提示

- 只监听 `127.0.0.1`，不要随意改为 `0.0.0.0`
- 报告与 CSV 可能包含明文凭据，分享前先脱敏
- 分析过程不会执行抓包或日志中的任何代码

需要一次分析多个抓包时，用“批量队列”；想写脚本或在没有图形界面的机器上运行，
请看[命令行]({{ '/manual/cli/' | relative_url }})。
